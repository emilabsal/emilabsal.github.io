# 🚀 emilabsal.github.io

## 📋 Описание

Репозиторий представляет собой коллекцию веб-проектов и лендингов, разработанных для различных компаний и задач. Включает в себя более 30 самостоятельных проектов: от корпоративных сайтов до интернет-магазинов и промо-страниц.

## 🛠 Технологический стек

- **HTML5** — разметка страниц
- **CSS3 / SCSS / SASS** — стилизация (препроцессоры: Prepros)
- **JavaScript (ES6+)** — интерактивность
- **jQuery** — в ряде проектов
- **Bootstrap** — в некоторых проектах
- **Owl Carousel** — слайдеры
- **LightGallery** — галереи
- **Wow.js / Animate.css** — анимации
- **PHP** — обработка форм (mail.php, send.php)
- **Jade/Pug** — шаблонизатор (в проекте `beboss`)

## 📦 Установка и запуск

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/emilabsal/emilabsal.github.io.git
```

2. Перейдите в директорию проекта:
```bash
cd emilabsal.github.io
```

3. Откройте любой `index.html` в браузере:
```bash
open Beaver/index.html
# или
start EVR/index.html  # для Windows
```

### Запуск с локальным сервером (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Или используя Node.js
npx serve .
```

Затем откройте `http://localhost:8000` в браузере.

## 💡 Примеры использования

### Открытие конкретного проекта

```bash
# Проект парфюмерного магазина
open EVR/index.html

# Проект строительной компании
open gis/index.html

# Проект медицинского центра
open alt/index.html
```

### Работа с SCSS

Для компиляции SCSS в CSS используйте Prepros (конфигурационные файлы `prepros.config` уже включены в проекты) или:

```bash
# Установка sass
npm install -g sass

# Компиляция
sass style.scss style.css
```
